# 恋みくじアプリ（最強版）

ボタンをクリックするだけで、今日の恋愛運を占うことができるシンプルなウェブアプリケーションです。

## 特徴

- **シンプル操作**: 「おみくじを引く」ボタンを押すだけで即座に結果が表示されます。
- **レスポンシブデザイン**: ピンクを基調とした、親しみやすいデザインを採用しています。
- **4種類の運勢**: 大吉、中吉、小吉、凶の4つの結果がランダムに表示されます。

## 構成ファイル

プロジェクトは以下の3つのファイルで構成されています。

1.  **index.html**: アプリケーションの構造（タイトル、ボタン、結果表示エリア）。
2.  **style.css**: アプリケーションのデザイン（背景色、ボタンのスタイル、フォント設定）。
3.  **script.js**: おみくじのロジック（ランダムな運勢の決定と画面への反映）。

## 使い方

1.  すべてのファイル（`index.html`, `style.css`, `script.js`）を同じフォルダに保存します。
2.  ブラウザで `index.html` を開きます。
3.  「おみくじを引く」ボタンをクリックして運勢を確認してください。

## 開発（カスタマイズ）

運勢の内容を変更したい場合は、`script.js` 内の `fortunes` 配列を編集してください。

```javascript
const fortunes =[
    "大吉　素敵な出会いがあるかも！",
    "中吉　少し勇気を出すと良いことが起きる",
    "小吉　今日はゆっくり過ごそう",
    "凶　無理せず慎重に行動しよう"
    // ここに新しい項目を追加できます
];
